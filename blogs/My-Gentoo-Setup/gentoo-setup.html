My Gentoo Setup

Hardware

I'm using a Thinkpad T480 that I got for $100 on ebay. It comes with a Intel Core i5-8250U, 16GB DDR4 ram, 256GB SSD, and a Intel UHD 620 graphics card.

Why Gentoo

I have used a different linux distros over the years like Ubuntu, Parrot, and Mint which were great for switching from windows to linux but I wanted to learn more about how to use linux. So I looked around for a little bit then saw Gentoo which allows me to build it from the ground up choosing packages I want to compile and install. With it also compiling packages I can disable or limit functions I dont want like Systemd and bluetooth.

OpenRC over Systemd

I orginally choosen OpenRC just to try it out but after doing research I have decided to stay with it. OpenRC is smaller with around 15,000 lines of code while SystemD has 1.3 million. I also notice that it takes less ram and can actually make my laptop boot quicker.
